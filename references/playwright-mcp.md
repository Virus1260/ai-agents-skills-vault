# Playwright MCP Server

- **Repository**: [https://github.com/microsoft/playwright-mcp](https://github.com/microsoft/playwright-mcp)
- **Description**: Model Context Protocol (MCP) server providing AI agents direct browser automation tools via Microsoft Playwright.

## Capabilities Provided to Agents
- `browser_navigate`: Navigate to arbitrary URLs.
- `browser_click`: Click elements using resilient accessibility selectors.
- `browser_type`: Fill input fields and trigger forms.
- `browser_screenshot`: Capture full-page visual captures for multimodal analysis.
