# Higgsfield AI (`higgsfield-ai`) Reference Guide

> **Organization**: [higgsfield-ai](https://github.com/higgsfield-ai)  
> **Key Repos**: `higgsfield` (GPU orchestration), `skills` (Creative agent skills), `cli` (Higgsfield CLI)

---

## Overview

Higgsfield AI is an open platform for training, serving, and automating video generation, cinematic motion, and multimodal creative workflows. The ecosystem provides both enterprise-grade GPU orchestration (fault-tolerant, scalable across billions of parameters) and dedicated agent skills for automated media creation.

---

## Imported Agent Skills

The following 8 specialized skills are integrated into the vault and active globally:

| Skill | Description & Use Case |
|---|---|
| `higgsfield-brandkit` | Generate consistent brand asset palettes, logos, and visual identities |
| `higgsfield-generate` | Generate cinematic video clips and text-to-video scenes via Higgsfield API |
| `higgsfield-marketplace-cards` | Create high-conversion visual ecommerce/product listing cards |
| `higgsfield-product-photoshoot` | Virtual product studio photography and 3D background staging |
| `higgsfield-soul-id` | Consistent character and face ID persistence across video sequences |
| `higgsfield-video-explainer` | Programmatic production of video explainers and marketing reels |
| `higgsfield-websites` | Generate generative visuals tailored for landing page heroes and layouts |
| `higgsfield-youtube-thumbnail` | Click-through-rate optimized YouTube thumbnail designs |

## CLI & SDK Usage

```bash
# Install Higgsfield CLI
pip install higgsfield

# Or via npm for Node.js / TypeScript
npm install @higgsfield/sdk
```
