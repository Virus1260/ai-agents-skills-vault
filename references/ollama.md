# Ollama — Local LLM Runner & Agent Engine

- **Repository**: [https://github.com/ollama/ollama](https://github.com/ollama/ollama)
- **Description**: Run open-weights models (Llama 3, DeepSeek-Coder, Qwen, Mistral) locally on CPU/GPU.

## Quick CLI Usage
```bash
ollama run deepseek-coder:6.7b
ollama run llama3.3:70b
```
## API Endpoint
Ollama provides an OpenAI-compatible REST API at `http://localhost:11434/v1`.
