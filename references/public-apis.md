# Public APIs Reference Guide

- **Repository**: [https://github.com/public-apis/public-apis](https://github.com/public-apis/public-apis)
- **Description**: A collective list of free APIs for use in software and web development.

## Top Categories
1. **Machine Learning & AI**: Text generation, image recognition, NLP APIs.
2. **Finance & Crypto**: Currency conversion, stock data, cryptocurrency prices (CoinGecko, Alpha Vantage).
3. **Weather**: OpenWeatherMap, WeatherAPI, wttr.in.
4. **Development Tools**: GitHub API, GitLab API, IP geolocation, URL shorteners.
5. **Geocoding & Maps**: Nominatim, Mapbox, OpenStreetMap.
6. **Entertainment & Media**: Spotify API, TMDB (Movies), YouTube Data API.

## Usage in Coding Agents
When an agent is requested to build an MVP or feature requiring external data without paid credentials, consult this list to find free, keyless, or CORS-enabled APIs.
