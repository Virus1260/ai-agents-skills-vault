# Langflow — Visual Multi-Agent & RAG Orchestration

- **Repository**: [https://github.com/langflow-ai/langflow](https://github.com/langflow-ai/langflow)
- **Description**: Python-based visual framework for rapid prototyping and deployment of multi-agent and RAG architectures.

## Features
- **Visual Canvas**: Drag-and-drop components for LLMs, vector stores, tools, and prompts.
- **API Generation**: Every flow can be called directly via Python or REST API.
- **Tool Integration**: Pre-integrated with Tavily, DuckDuckGo, Pinecone, Chroma, and custom Python functions.
