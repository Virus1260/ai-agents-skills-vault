# Motion Primitives — UI Motion & Micro-Interactions

- **Website**: [https://motion-primitives.com/](https://motion-primitives.com/)
- **Repository**: [https://github.com/ibelick/motion-primitives](https://github.com/ibelick/motion-primitives)
- **Description**: Beautiful animation primitives and micro-interactions built with Framer Motion and Tailwind CSS.

## Key Primitives
- **Fluid transitions**: Smooth layout animations, morphing modals, and floating navigation bars.
- **Interactive Cards**: Tilt effects, magnetic buttons, shimmering text, and glowing borders.
- **Scroll triggers**: Parallax cards, progressive reveal, and sticky dock menus.
