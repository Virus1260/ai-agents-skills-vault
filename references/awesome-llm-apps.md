# Awesome LLM Apps Reference Guide

- **Repository**: [https://github.com/shubhamsaboo/awesome-llm-apps](https://github.com/shubhamsaboo/awesome-llm-apps)
- **Description**: Curated collection of production-grade AI agent applications, RAG pipelines, and multi-modal workflows.

## Popular Patterns Included
1. **Multi-Agent Research Teams**: LangGraph / CrewAI / AutoGen implementations.
2. **Hybrid RAG Systems**: BM25 + Dense vector embeddings + cross-encoder reranking.
3. **Voice & Audio Agents**: Real-time speech-to-speech agents using Whisper and ElevenLabs.
4. **Autonomous Web Agents**: Browser automation agents using Playwright and LLM vision.
