2. **Main Dashboard**: Real-time overview of metrics, tasks, and recent activity.

## 6. Non-Functional Requirements
- **Performance**: Lighthouse score $\ge 90$, FCP $< 1.2$s.
- **Accessibility**: WCAG 2.2 AA compliance, visible focus rings, full keyboard navigation.
- **Security**: Strict input sanitization, CSRF/XSS protection, encrypted data at rest.
