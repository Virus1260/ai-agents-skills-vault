# Cybersecurity Resources & Knowledge Base

Comprehensive directory of curated cybersecurity resources, cheat sheets, learning paths, tools, labs, and certification roadmaps.

## Full Reference Guide
The complete unabridged guide is located at:
[Cybersecurity Resources Reference](../../references/cybersecurity-resources/README.md)

## Core Domains Covered
1. **Getting Started**: Books, legal PDFs, top YouTube channels, podcasts, foundations.
2. **Hacking & Security Challenges**: CTF platforms (TryHackMe, HackTheBox, Juice Shop, PortSwigger Web Security Academy, CyberSecLabs).
3. **Bug Bounty Programs**: HackerOne, Bugcrowd, methodology guides, disclosure standards.
4. **Hacking Techniques**: Network attacks, web exploitation, wireless penetration testing, social engineering, physical security.
5. **Operating Systems & Linux**: Linux commands, scripting, privilege escalation, Windows security.
6. **Web Application Security**: OWASP Top 10, XSS, SQLi, SSRF, IDOR, CSRF, API security testing.
7. **Cybersecurity Tools**: Nmap, Wireshark, Burp Suite, Metasploit, Gobuster, Nikto, John the Ripper, Hydra.
8. **Digital Forensics & Incident Response (DFIR)**: Autopsy, Volatility, memory analysis, disk imaging.
9. **OSINT**: Maltego, Recon-ng, Google Dorking, Spiderfoot, social media intelligence.
10. **Certifications Roadmap**: CompTIA Security+, CEH, OSCP, CISSP, eJPT, PNPT.
